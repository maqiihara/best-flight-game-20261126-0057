Kitehawk Ridge Run — a complete, original bush-plane flight game. Fly the Kitehawk through sky rings over a mountain valley, drop a supply crate on the hut meadow, and land on the valley strip at dusk. Three missions, fuel and damage that turn every sortie into decisions, a lit HUD with altitude, speed and heading, and procedural engine sound — all offline, from static files, played with keyboard and mouse.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. Arrows / WASD fly, Shift throttles up, Ctrl throttles down, the mouse steers, click drops the crate, Space starts, P pauses, M changes mission.
